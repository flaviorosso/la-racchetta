# LA RACCHETTA – SALGADOS MVP V2

## Projeto estático pronto para Netlify

- Repositório: https://github.com/flaviorosso/la-racchetta
- Site em HTML/CSS/JS puro
- Compatível com deploy em Netlify sem build step

## Como publicar no Netlify
1. Acesse https://app.netlify.com
2. Clique em "Add new site" > "Import an existing project"
3. Conecte sua conta GitHub e selecione o repositório `flaviorosso/la-racchetta`
4. Em `Publish directory`, use `.`
5. Deixe `Build command` vazio
6. Clique em `Deploy site`
